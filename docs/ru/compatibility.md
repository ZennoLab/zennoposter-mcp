# Совместимость

Русский перевод — вспомогательный; при расхождении верной считается [английская версия](../compatibility.md).

Здесь независимо движутся три версии: установленный продукт, контракт API, который он обслуживает, и скачанные вами бинарники MCP-серверов. Эта страница связывает их между собой.

## Поддерживаемые сочетания

Версия контракта: **1.1.0**.

## Как узнать версии у живой установки

Один вызов даёт версию контракта и сборку продукта за ним. 5299 ниже — это ProjectMaker в ZennoPoster; для любого другого сочетания возьмите порт из таблицы выше.

```bash
curl -H "Authorization: Bearer <api-key>" http://localhost:5299/api/v1/capabilities
```

- `version` — версия контракта, которую обслуживает этот хост.
- `productVersion` — сборка продукта за ним. Пустое или отсутствующее значение означает, что хост его не сообщает: читайте это как «неизвестно», а не как «старая версия».
- `operations` — авторитетный список для этой установки: операцию, которой там нет или у которой `isAvailable: false`, вызвать нельзя.

Версия MCP-сервера — та, что стоит в теге релиза и в имени архива, например `mcp-projectmaker-v0.2.0` и `MCP.ProjectMaker-v0.2.0-win-x64.zip`.

## Если номера не совпадают

Если `version` из `/capabilities` ниже версии контракта выше, ваша установка старше этой документации — обновите продукт или опирайтесь на тот список операций, который она реально сообщает.
